# LaterZero

Chrome Manifest V3 extension for clearing YouTube **Watch later**. The original 19-line console script has been replaced with sequential, cancellable UI automation. No build is needed for the extension or landing page.

## Установка в Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика / Developer mode**.
3. Нажмите **Загрузить распакованное расширение / Load unpacked** и выберите папку `extension` этого проекта.
4. Закрепите LaterZero в панели браузера.
5. Откройте <https://www.youtube.com/playlist?list=WL> и дождитесь загрузки списка.
6. Нажмите значок расширения, подтвердите очистку и нажмите **Start clearing**.

В правом верхнем углу YouTube появится панель: число подтверждённых удалений, время и **Stop**. Закрытие popup не останавливает очистку. Stop запрещает следующие удаления; уже отправленное действие может закончиться. Перезагрузка вкладки также прерывает скрипт. Повторный запуск — новая сессия со счётчиком с нуля.

**Удаление меняет ваш настоящий плейлист. Автоматического восстановления нет.**

## Поведение и ограничения

- Запускается только на HTTPS `youtube.com/playlist?list=WL` или `www.youtube.com/playlist?list=WL`. При смене страницы останавливается.
- Обрабатывает видео последовательно, ждёт меню до 5 секунд и исчезновения строки после удаления до 15 секунд. Если результат не подтверждён — останавливается без повтора.
- Обрабатывает классические строки `ytd-playlist-video-renderer` и новые `yt-lockup-view-model` внутри контейнера плейлиста. Рекомендации вне списка не обрабатываются.
- Между удалениями выдерживает паузу. После исчерпания строк прокручивает страницу и несколько раз проверяет подгрузку.
- Основные языки меню: английский и русский. Также добавлены шаблоны немецкого, французского, испанского и португальского; они не проверены на живом YouTube. Если действие не распознано, переключите язык YouTube на English.
- Держите вкладку открытой и желательно активной. Не меняйте сортировку и не управляйте плейлистом вручную во время очистки. На фоне браузер может замедлять таймеры.
- Не использует приватные API YouTube, не читает cookies и не отправляет данные разработчику. Изменения плейлиста выполняет сама страница YouTube через текущую авторизованную сессию.
- Разрешения: только `activeTab` и `scripting`. Постоянного доступа ко всем сайтам, фонового service worker и внешнего кода нет.
- Совместимость с реальным YouTube требует ручной проверки: разметка и экспериментальные варианты интерфейса могут меняться. Автотесты подтверждают поведение на имитации DOM, а не удаление на сервере YouTube.

## Лендинг

Файлы находятся в `landing/`. Рабочее название LaterZero. Открывайте `landing/index.html` напрямую или запускайте:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory landing
```

Кнопка получения расширения открывает инструкцию локальной установки и ссылку на ZIP `landing/downloads/laterzero-extension.zip`. Публикации в Chrome Web Store пока нет. Демо использует вымышленные записи и не меняет настоящий YouTube.

## Проверки

```sh
npm ci
npm run check
npm test
```

Тесты покрывают английский и русский UI, задержки, неподтверждённое удаление, Stop до/после клика, смену URL, повторный запуск, подгрузку, пустой список и неоднозначные меню.

## Проверка перед релизом

Загрузите `extension` в Chrome. На своей странице Watch later сначала запустите очистку и остановите после 1–2 записей. Обновите страницу и проверьте, что удаление сохранилось. Повторите для английского и русского интерфейса и списка с подгрузкой. Это действие удаляет записи из настоящего списка; выполняйте только с видео, которые хотите убрать.
